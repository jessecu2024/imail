# Homebrew tap setup

How to publish imail on a personal Homebrew tap so Mac users can
`brew install jessecu2024/tap/imail`.

The formula source lives at [`imail.rb`](imail.rb) in this directory.
Homebrew itself requires the formula to live in a separate repo named
with the `homebrew-` prefix.

## One-time tap setup

```bash
# 1. Create the tap repo (public, can be empty).
gh repo create jessecu2024/homebrew-tap --public --description "Personal Homebrew tap"

# 2. Clone and add the Formula directory.
git clone https://github.com/jessecu2024/homebrew-tap
cd homebrew-tap
mkdir -p Formula
cp ../imail/packaging/homebrew/imail.rb Formula/imail.rb
```

Before committing, fill in the two placeholders in `imail.rb`:

- `sha256 "<<<PLACEHOLDER>>>"` — run `shasum -a 256` on the sdist from
  [PyPI](https://pypi.org/project/imail-cli/#files) and paste the hash.
- Python resource blocks — generated by `homebrew-pypi-poet`:

  ```bash
  pipx install homebrew-pypi-poet
  python3.12 -m venv /tmp/imail-poet
  /tmp/imail-poet/bin/pip install imail-cli==1.3.0
  /tmp/imail-poet/bin/python -m pip install homebrew-pypi-poet
  /tmp/imail-poet/bin/poet imail-cli
  # → paste the `resource "..." do ... end` blocks where the
  #   PYTHON DEPENDENCY RESOURCES marker is.
  ```

Then commit + push the tap:

```bash
git add Formula/imail.rb
git commit -m "Add imail 1.3.0"
git push
```

## Users install

```bash
brew tap jessecu2024/tap
brew install imail
imail
```

## On every imail release

Bump the formula:

1. Update `url` to the new version's sdist URL.
2. Re-run `shasum -a 256` and update `sha256`.
3. Re-run `poet imail-cli` and replace the resource blocks (transitive
   deps may have changed too).
4. Commit on the tap repo: `Bump to 1.x.y`.

If imail's runtime deps haven't changed in a release, only steps 1 + 2
are needed. The poet step is only for new transitive resolutions.

## Future: ship the formula automatically

A workflow on the **imail** repo could open a PR against the **tap**
repo on every PyPI publish, bumping `url` + `sha256` + resources. Not
wired up yet — manual bump is fine while imail is one maintainer.
